# PC 风道仿真器（网页版）使用说明

## 打开

- **最简单**：下载 `web/release/pcflow-web.html`（一个文件），用 Chrome 或 Edge 双击打开即可，不需要联网、
  不需要安装任何东西（已在 Chromium 内核上测试；Firefox、Safari 未测试）。
- 自己构建：`cd web && npm install && npm run dev`（开发服务器），或 `npm run build` 后把 `dist/` 放到任意静态网站。

> ⚠ 这是 **2D 定性模型**：机箱按侧视截面（默认紧凑 ATX 机箱，深 320 mm × 高 400 mm，主板贴后壁）、固定深度计算，用来比较风道方案的趋势（哪种布局更凉、
> 哪里有死区、风扇是否在高背压下工作），不是某台真实机器的精确温度。

## 界面一览

页面顶部可在 **仿真** 与 **方案对比展示** 两页之间切换（见"常见用法"第 5 条）。仿真页左侧是机箱侧视图（左 = 后部 I/O，右 = 前面板，上 = 顶部），
下面是温度曲线或风扇工作点图；右侧是操作按钮与 4 个标签页。

| 区域 | 作用 |
|---|---|
| 视图按钮 | 速度 / 温度 / 压力 / 涡量 / 固体温度 / 温差（与某个已保存方案相减） |
| ▶ 开始仿真 | 连续推进流场（每步 5 ms 物理时间）；再点暂停 |
| ⏩ 跑到稳态 | 一直推进到 CPU/GPU/电源结温、机箱内温与风量都不再变化（窗口均值判据）；可随时停止 |
| 重置 | 流场回到静止、室温 |
| 网格 | 预览 140²（快，约 0.1 s/步）或精确 280²（约 0.4–0.6 s/步，网格更细、结果更准） |
| 精确模式 | 与网格无关的另一个开关：每步按当前系数重装全部矩阵，约慢 2 倍；默认的"每 5 步重装"在已对照的布局上与它相差 ≤ 0.1°C（旧版本的个别布局约 0.5°C） |
| 粒子 / 风量标注 | 粒子示踪显示气流走向；开口旁的箭头与数字是净风量（CFM，橙 = 流出，青 = 流入） |
| 导出 PNG / 录制 GIF | 保存当前视图（含标题与色标）/ 录一段动画 |

鼠标在视图上移动时，下方显示该点的位置（mm，相对机箱外沿）、风速、温度与静压。

## 常见用法

### 1. 看默认配置的散热情况
1. 点 **⏩ 跑到稳态**（默认布局：预览网格约 850 步、1 分钟左右；精确 280² 网格约 850 步、5 分钟左右，布局不同会更久）。
2. 在 **状态** 页看 CPU/GPU/电源温度、机箱内温、噪音、综合评分与智能诊断建议。
3. 切到 **温度** 视图看热量聚集在哪里；**速度** 视图配合粒子看气流是否短路（进风直接被排走）。

### 2. 调功率或风扇转速
- **功率与风扇** 页：拖动 CPU / GPU / 电源负载功率，或点"办公 / 游戏 / 满载"。新功率立即生效，但温度要随仿真推进才会变：
  仿真暂停时（例如"跑到稳态"结束后）改功率或全局风扇转速，会自动继续仿真，温度曲线随之变化；想看新的稳态，再点"跑到稳态"。
- 风扇转速：默认"自动温控"（按 CPU/GPU 温度调速）；点按钮切到"手动"后用滑块设定全局转速。
  单台风扇也可以在 **风扇布局** 页单独设为固定转速。
- 温控曲线：**静音 / 标准 / 性能** 三档（默认标准），决定各温度下风扇转多快。静音档同样温度下转得慢、更安静但更热，
  性能档反之。显卡风扇在显卡低于 50°C 时停转（标准档；升到 55°C 才重新转），电源负载低于 40% 且不热时电源风扇也停转
  （半被动），表格里转速显示"停"、不计噪音。办公场景下通常就是这样。档位会随"保存配置"写入 JSON。
  显卡风扇停转时散热片只剩自然对流与少量机箱气流，大约只够 55 W（真实的三风扇显卡也是这样：待机、看视频时停转，
  玩游戏时升到 55°C 风扇就转起来）：办公场景（35 W）停转、显卡约 42°C，游戏、满载场景风扇转。显卡功率约 60–80 W 时
  风扇会在停转与最低转速之间来回切换（回差 50 / 55°C），温度在 50–55°C 之间波动。
- 表格里是每台风扇的转速、实测/自由风量、工作点静压、噪音与声能占比；下面一行说明最响的风扇噪音由哪几部分组成。
- 下方切到 **风扇工作点** 图：曲线是风扇在当前转速下的 P-Q 特性，圆点是实际工作点。圆点靠近曲线左上（高静压、
  低风量）说明风阻大、风扇在"憋着"转，噪音会升高。

### 3. 改风扇位置（布局）
1. 打开 **风扇布局** 页。直接点击主视图机箱边上的虚线框（7 个安装位：前 3、顶 2、后 1、底 1），每点一次在
   空 → 进气 → 排气 之间切换；或在表格里改状态、型号、转速。机箱里的主板区、CPU 底座虚线框只表示位置，不挡风、不能点。
   CPU 双塔散热器画成前后两个蓝框，塔扇（青色）在两组鳍片中间和前侧；显卡风扇是橙色虚线框——显卡横插在主板上，
   侧视看到的是卡的侧边，风扇在卡底面朝下、看不到扇叶，但照常向上吹风。
   显卡、内存、VRM 散热片只占主板到侧板距离的一部分（显卡约 80%），旁边还有空隙可以过风，所以它们不是实心障碍：
   速度图里显卡所在区域也有气流，显卡热风从卡的顶边（侧板方向）排出后向上走，会被 CPU 散热器吸进去——这与真实机箱相同。
2. 也可以"载入预设"（正压、负压、前进顶出、底进顶出等 8 种）。
3. 下方显示标称进/排风量与机箱压力状态（正压 / 负压 / 平衡），以及安装冲突检查（风扇重叠、超出壁面、与电源冲突）。
4. 电源仓挡板前部开孔、显卡厚度（2.5–4 槽）、CPU 散热器塔扇数量（1 个装中间 / 2 个前 + 中间）也在这里改。
   1.3 版之前保存的配置里 CPU 散热器是单塔，照常读取，按单塔、1 个前置塔扇计算（下拉框变为"前侧 / 前 + 后"）。
5. 点 **应用布局**（或 **应用并跑到稳态**）才会生效；应用会让流场从静止重新开始。
6. **保存配置（JSON）/ 载入配置（JSON）**：文件格式与 MATLAB 版相同，可以互相读写。
   v1.1 之前保存的配置（400 mm 见方机箱）照常读取和计算，但安装位与"前部开孔"是按新的默认机箱定义的：
   顶部 140/260 mm 等不在新安装位上的风扇照常运转、表格里却不显示（布局页会提示有几台），"前部开孔"会开在
   280–318 mm。想在旧机箱上继续编辑风扇，最好先"载入预设"或在新默认布局上重新摆放。

> 预览网格（140²，4 mm 一格）用来快速看气流走向。1.6 版起它与精确网格（280²）的差别小了很多：默认布局 GPU 高约 2°C、CPU 与风量
> 几乎相同，其它布局 CPU 低 0–4°C、GPU 相差 ±2°C 左右，但风量可能少 5–18%；仍可能把相差 2°C 以内的两个布局排反（例如默认与
> 正压谁的显卡更凉）。
> 比较温度、下结论时请切到 **精确 280²** 再跑到稳态，或直接看"方案对比展示"页（预计算用的就是精确网格）。结温的绝对值
> 有几度的不确定性，适合在同一网格上比较不同方案，不宜当作真实读数。

### 4. 比较两种方案
1. 当前布局跑到稳态后，在 **方案对比** 页选 A，点"保存当前"。
2. 改布局 / 功率 / 风扇后再跑到稳态，选 B，"保存当前"。
3. 表格逐项对比结温、内温、风量、压力状态、噪音、性能、评分（档）、风扇曲线、死区比例等（"稳态"一栏为"否"表示保存时还没跑到稳态）。
   评分按功率分档，不同档的总分不能直接比较；比较风扇方案时请保持功率相同。
4. 选参考方案后点"显示温差"：温差视图 = 当前 − 参考方案，红色表示当前更热（两个方案须是同一网格精度）。
5. "载入布局"可回到某个方案继续调整。方案只保存在当前页面，刷新即清空；要长期保存请用 JSON 配置。

### 5. 一眼对比各风扇方案（方案对比展示页）
页面顶部点 **方案对比展示**（再点 **仿真** 回来，仿真页的状态保留）。打开即显示内置的预计算结果：8 种风扇布局 × 办公 / 游戏 / 满载，
精确 280² 网格、自动温控（标准曲线），不用等计算。
1. **三个场景总览**：每格是该方案在该场景的评分（颜色越绿越好）与 CPU/GPU 结温、噪音；有降频时另显示频率保持率。点格子切换下面的场景。
   评分按功率分档（办公看重安静、满载看重不降频），同一列里比较；办公场景各方案都很安静、温度也低，分数差别小。
2. **各方案卡片**：侧视缩略图（温度或风速，右上角切换）、结温、噪音、性能、机箱内温、风量与评分；"最高分""最凉""最安静"标在卡片上。
   点 **在仿真页打开**：载入这个方案与场景的功率，回到仿真页并跑到稳态，可以接着改布局细调（仿真页按当前网格档计算）。
3. **指标对比**：选一个指标（评分、最高结温、噪音、性能、风量、机箱热阻等），各方案按好坏排成条形图。
4. **公平比较：同噪音 / 同温度**：自动温控下各方案的风扇转速不同，直接比温度不公平。这里把全部风扇固定在 40 / 70 / 100% 转速各算一次，
   画成"噪音—温度"曲线，曲线越靠左下越好。拖动滑块：同噪音时比较各方案的最高结温（与性能），同温度时比较各方案需要多大噪音。
   满载时低转速可能触发温度墙降频，结温停在降频阈，这时看"性能"一栏。
5. **加入自定义方案**：把仿真页当前已应用的布局（含温控曲线）按同样的口径在后台计算三个场景，加入上面的对比。精确 280² 约 1.5–2 小时，
   预览 140² 约 20 分钟（结果标"预览网格"，GPU 可能差几 °C）；可不含转速扫描（快一半，但不参加公平比较）。计算在后台线程进行，
   可以切回仿真页继续操作（两边同时算会互相拖慢）；结果只保存在当前页面，刷新即清空。布局里设为固定转速的风扇在转速扫描中
   保持自己的转速。仿真页正在"跑到稳态"时点"在仿真页打开"，会停止原来的推进、载入新方案后重新跑到稳态。
   卡片上标"未完全稳态"表示统计时间内结温还在变化（超过 0.3°C），数值可能差 1–3°C（办公场景风扇都在最低转速，变化最慢），排名仅供参考。

## 读数怎么理解

- **结温**：CPU/GPU 芯片温度（热网络模型：芯片 → 导热 → 散热片 → 空气）。芯片按真实规律降频：
  结温越高，加速频率略降（CPU 60°C、GPU 50°C 以上每 10°C 约降 1%）；散热跟不上时触发**温度墙**，降低频率把结温压在
  降频阈（CPU 95°C、GPU 87°C），功率随频率近似按三次方下降；降到最低频率（50%）仍压不住才算过热。
  触发温度墙或过热时状态页的温度标红，智能诊断给出当前频率与功率。功率滑块设的是满频时的功率。
- **性能 %**：频率保持率（CPU、GPU 按功率加权）。100% 表示满频；只看频率，不换算成帧率。
- **机箱内温**：机箱内部所有空气格的平均温度。
- **风量（CFM）**：机箱开口（不含电源自带风道）的总出风量。
- **噪音 dB(A)**：机箱前方约 1 m 处的估算声压级，各风扇按能量叠加：转速主项（厂家满速噪音，按风扇定律随转速下降，
  半速约低 15 dB）+ 工作点（背压过高/近失速）+ 格栅/滤网 + 鳍片（塔扇、显卡风扇 +2 dB）+ 安装位置修正。
  风扇型号的转速、风量、噪音、静压取自厂家数据（Noctua、Arctic、Phanteks 等）。
- **死区**：机箱内风速 < 0.1 m/s 的区域占比，越大说明越多地方空气不流动。
- **综合评分**：按 CPU+GPU 功率分档（办公 < 187.5 W、游戏 < 400 W、其余满载），四项加权（与 MATLAB 版相同）：
  - 性能：频率保持率，90% → 0 分、100% → 100 分；
  - 温度：离温度墙越远越高（降频阈 → 0 分、环境温度 → 100 分），过热记 0，电源超温再扣 20；
  - 噪音：按人耳响度，10 dB(A) → 100 分、45 dB(A) → 0 分（19 dB 约 92 分、30 dB 约 71 分）；
  - 风道：机箱热阻，即每 100 W 发热使机箱内空气与 CPU/GPU 进风平均升温多少度，按对数计分：1°C → 100 分、2°C → 75 分、
    4°C → 50 分、16°C → 0 分；
  - 权重（性能/温度/噪音/风道）：办公 10/15/60/15、游戏 25/25/35/15、满载 35/30/20/15。办公看重安静，满载看重不降频。
  - 办公场景风扇都在最低转速、几乎听不见，各布局总分相差不大；比较风扇布局主要看游戏、满载场景。

## 常见问题

- **浏览器变慢**：精确 280² 网格每步约 0.5 s，界面仍可操作；想快就用预览网格。计算在后台线程进行，不会卡住界面。
- **"计算发散"**：某些极端设置下数值不稳定，点"重置"再试；若可复现，保存 JSON 配置反馈给开发者。
- **"读取配置失败" / "重建失败，已保留原布局"**：载入的配置有无效参数（例如风扇型号不在型号库中、噪音参数超出范围、
  计算域尺寸不合理），界面和流场都保持原样，按提示修改配置后再载入。
- **拖动功率滑块**：松手时才生效；"正在重建流场…"期间功率、风扇与精确模式控件暂时不可用。
- **和 MATLAB 版的差别**：计算结果与 MATLAB 版一致（同一算法，逐步对照到舍入误差）；界面布局相同，只是换成网页。
