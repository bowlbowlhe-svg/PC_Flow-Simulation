# PC 风道仿真器 路线图（MATLAB 定稿 → 网页版）

目标：先在 MATLAB 上把模型修正、功能做完并定稿（v4.x），再以定稿版本为"标准答案"移植到网页版。

## 工作方式

- 每个阶段都有**开发 → 测试 → 审计**三步，阶段完成后自动推进到下一阶段。
- **测试**：开发环境没有 MATLAB，使用 GNU Octave 8.4 + `matlab_app/compat/octave/` 兼容层做无界面数值自检；
  界面测试 `test_ui` 在 Octave 下用 `tests/ui_mock/` 桩对象驱动同一套回调（能发现逻辑与接口错误，
  不能发现 MATLAB 控件的显示问题）。最终以 MATLAB 下的 `run_all_tests` 结果为准。
- **审计**：每个阶段结束由独立审计（代码审阅 + 复核测试证据）把关，审计发现的问题在进入下一阶段前修复。
- 每个阶段单独提交，提交信息写明验收结果。

## 阶段 0：基线入库
- 原始 v3.3.1 代码原样入库。
- Octave 下跑三场景（400 步）与守恒测试（1200 步），结果存 `matlab_app/tests/baseline/v3.3.1_octave/`，作为阶段 1"不改物理"的逐位对照。

## 阶段 1：整理与配置化（不改物理）
- 目录整理：`src/`（求解器与布局配置）、`app/`（界面）、`tests/`、`tools/`、`docs/`。
- 布局配置化：机箱、元件、风扇的几何与参数由配置结构体描述（可存 JSON），求解器从配置构建。
- 删除死代码；注释里的版本历史移入 `CHANGELOG.md`；README 瘦身。
- 修复 `resetSim` 漏复位内置风扇 `lastFlowFactor`；新增求解器级 `reset()`。
- 测试统一入口 `run_all_tests`。
- **验收**：默认场景 400 步后全部场（T、u、v、p、k、ω）与基线逐位一致。

## 阶段 2：物理修复（每项配验证）

实际执行时十余项合并为一个提交（v3.5.0），审计发现的问题在 v3.7.0 中修复（见 CHANGELOG）。

| 修复 | 验证 |
|---|---|
| 扩散系数补 1/L²（原来弱 3.23 倍） | 高斯温度包扩散 vs 解析解 |
| 浮力补 `/VEL_SCALE`（原来只有 56%） | 差分加热方腔自然对流 vs de Vahl Davis 1983 的 Nu |
| 风扇改真正的薄盘（作用区厚度与压升换算一致） | 单风扇 + 已知阻力直风道：工作点落在 P-Q 与系统曲线交点 |
| 去掉进气盘 25°C 重置热汇 | 能量账本闭合，新风冷却只由开口平流体现 |
| 结温环境温度改为散热器进风侧 CFD 温度，h 用穿鳍风速 | 代数轨保留为交叉校验 |
| GPU 热阻栈按公开数据重标定（~0.1 K/W 量级） | 三场景自动风扇不再全部顶满 |
| PSU 损耗按负载 × 效率曲线；去掉"节流"改为过温告警 | — |
| 能量计账公式同步 | 守恒测试 A、B2 闭合 |

## 阶段 3：性能
- profile 定位热点；扩散避免频繁重分解；按收敛判据"跑到稳态"；140² 预览档与 280² 精确档误差对照。
- 目标（profile 后定具体数字）：精确档单布局到稳态 ~1 分钟量级，预览档 ~10 秒量级。
- 实际（Octave 单线程）：精确档约 5 分钟、预览档约 1 分钟，未达到目标。主要耗时是每步 4 次
  稀疏三角求解与半拉格朗日插值，进一步提速需改算法（多重网格、显式平流子步），
  留给网页版（WebAssembly/GPU）处理。MATLAB 下的实际耗时待用户实测。

## 阶段 4：风扇布局编辑
- 安装位：前 3、顶 2、后 1、底 2（`fan_slots`）；每位可设空/进气/排气、型号、转速模式（自动/固定百分比）。
  400 mm 机箱放不下两台并排的 120 mm 底部风扇，2D 简化为重叠 12 mm。
- 自动温控分传感器；电源仓挡板"前部开孔"选项；预设布局；方案 A/B/C 对比表与温差图；配置存 JSON。
- 2D 限制：侧板风扇无法表示。

## 阶段 5：噪音模型
- 保留转速主项与多扇能量叠加；新增工作点（背压/近失速）与格栅/滤网经验修正；显示每扇贡献。

## 阶段 6：可视化
- 粒子示踪动画（替换每帧重算的 streamslice）；开口风量标注；风扇工作点图；压力场视图；
  感知均匀色图；悬停读数；PNG/GIF 导出。

## 阶段 7：定稿
- 算法规格文档（方程、离散、单位、参数）；多布局"标准答案"数据集；冻结计算代码。
- 完成：`docs/ALGORITHM.md`；`matlab_app/tests/reference/`（`tools/make_reference_dataset`）；
  `test_reference`（v4.0.0）。审计修复（v4.2.0）：插值、最近流体格、pchip 改为自带实现，MATLAB 与
  Octave 同口径；规格补全整数几何、边界、k-ω、风扇等细节；稳态算例改为长时统计；数据集加入几何与
  第 1/10/200 步快照。
- "冻结"的前提是 MATLAB 下 `run_all_tests('full')` 通过、`test_reference` 差异为舍入量级（待用户在
  MATLAB 下实测）；实测前计算代码仍可能为 MATLAB 兼容性修改。

## 下一步：网页版
- 以 `docs/ALGORITHM.md` 为规格、`tests/reference/` 为验收数据移植（建议 TypeScript + WebGL/WebGPU
  或 WebAssembly 线性代数）；先对固定步数算例逐场对照，再对稳态算例对照结温/风量/噪音。
- 界面沿用 MATLAB 版的布局编辑、方案对比、粒子示踪与压力视图。
- MATLAB 版进入维护：只修缺陷，不加功能。
