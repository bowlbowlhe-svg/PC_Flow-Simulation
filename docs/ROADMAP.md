# PC 风道仿真器 路线图（MATLAB 定稿 → 网页版）

目标：先在 MATLAB 上把模型修正、功能做完并定稿（v4.x），再以定稿版本为"标准答案"移植到网页版。

## 工作方式

- 每个阶段都有**开发 → 测试 → 审计**三步，阶段完成后自动推进到下一阶段。
- **测试**：开发环境没有 MATLAB，使用 GNU Octave 8.4 + `matlab_app/compat/octave/` 兼容层做无界面数值自检；
  界面测试 `test_ui` 在 Octave 下用 `tests/ui_mock/` 桩对象驱动同一套回调（能发现逻辑与接口错误，
  不能发现 MATLAB 控件的显示问题）。最终以 MATLAB 下的 `run_all_tests` 结果为准。
- **审计**：每个阶段结束由独立审计（代码审阅 + 复核测试证据）把关，审计发现的问题在进入下一阶段前修复。
- 每个阶段单独提交，提交信息写明验收结果。

## 阶段 0：基线入库
- 原始 v3.3.1 代码原样入库。
- Octave 下跑三场景（400 步）与守恒测试（1200 步），结果存 `matlab_app/tests/baseline/v3.3.1_octave/`，作为阶段 1"不改物理"的逐位对照。

## 阶段 1：整理与配置化（不改物理）
- 目录整理：`src/`（求解器与布局配置）、`app/`（界面）、`tests/`、`tools/`、`docs/`。
- 布局配置化：机箱、元件、风扇的几何与参数由配置结构体描述（可存 JSON），求解器从配置构建。
- 删除死代码；注释里的版本历史移入 `CHANGELOG.md`；README 瘦身。
- 修复 `resetSim` 漏复位内置风扇 `lastFlowFactor`；新增求解器级 `reset()`。
- 测试统一入口 `run_all_tests`。
- **验收**：默认场景 400 步后全部场（T、u、v、p、k、ω）与基线逐位一致。

## 阶段 2：物理修复（每项配验证）

实际执行时十余项合并为一个提交（v3.5.0），审计发现的问题在 v3.7.0 中修复（见 CHANGELOG）。

| 修复 | 验证 |
|---|---|
| 扩散系数补 1/L²（原来弱 3.23 倍） | 高斯温度包扩散 vs 解析解 |
| 浮力补 `/VEL_SCALE`（原来只有 56%） | 差分加热方腔自然对流 vs de Vahl Davis 1983 的 Nu |
| 风扇改真正的薄盘（作用区厚度与压升换算一致） | 单风扇 + 已知阻力直风道：工作点落在 P-Q 与系统曲线交点 |
| 去掉进气盘 25°C 重置热汇 | 能量账本闭合，新风冷却只由开口平流体现 |
| 结温环境温度改为散热器进风侧 CFD 温度，h 用穿鳍风速 | 代数轨保留为交叉校验 |
| GPU 热阻栈按公开数据重标定（~0.1 K/W 量级） | 三场景自动风扇不再全部顶满 |
| PSU 损耗按负载 × 效率曲线；去掉"节流"改为过温告警 | — |
| 能量计账公式同步 | 守恒测试 A、B2 闭合 |

## 阶段 3：性能
- profile 定位热点；扩散避免频繁重分解；按收敛判据"跑到稳态"；140² 预览档与 280² 精确档误差对照。
- 目标（profile 后定具体数字）：精确档单布局到稳态 ~1 分钟量级，预览档 ~10 秒量级。
- 实际（Octave 单线程）：精确档约 5 分钟、预览档约 1 分钟，未达到目标。主要耗时是每步 4 次
  稀疏三角求解与半拉格朗日插值，进一步提速需改算法（多重网格、显式平流子步），
  留给网页版（WebAssembly/GPU）处理。MATLAB 下的实际耗时待用户实测。

## 阶段 4：风扇布局编辑
- 安装位：前 3、顶 2、后 1、底 1（`fan_slots`；v4.3.0 之前为 400 mm 见方机箱，底部 2 个按 2D 简化重叠 12 mm）；
  每位可设空/进气/排气、型号、转速模式（自动/固定百分比）。
- 自动温控分传感器；电源仓挡板"前部开孔"选项；预设布局；方案 A/B/C 对比表与温差图；配置存 JSON。
- 2D 限制：侧板风扇无法表示。

## 阶段 5：噪音模型
- 保留转速主项与多扇能量叠加；新增工作点（背压/近失速）与格栅/滤网经验修正；显示每扇贡献。

## 阶段 6：可视化
- 粒子示踪动画（替换每帧重算的 streamslice）；开口风量标注；风扇工作点图；压力场视图；
  感知均匀色图；悬停读数；PNG/GIF 导出。

## 阶段 7：定稿
- 算法规格文档（方程、离散、单位、参数）；多布局"标准答案"数据集；冻结计算代码。
- 完成：`docs/ALGORITHM.md`；`matlab_app/tests/reference/`（`tools/make_reference_dataset`）；
  `test_reference`（v4.0.0）。审计修复（v4.2.0）：插值、最近流体格、pchip 改为自带实现，MATLAB 与
  Octave 同口径；规格补全整数几何、边界、k-ω、风扇等细节；稳态算例改为长时统计；数据集加入几何与
  第 1/10/200 步快照。
- "冻结"的前提是 MATLAB 下 `run_all_tests('full')` 通过、`test_reference` 差异为舍入量级：v4.2.1 已由用户在
  MATLAB 下实测通过（与 Octave 标准答案最大差 5e−5°C，即存储舍入）。v4.2.1/v4.2.2 两轮审计把扩散算子的
  重装改为每 5 步固定间隔，此后计算代码冻结，只修缺陷。

## 网页版（阶段 W0–W5）

以 `docs/ALGORITHM.md` 为规格、`matlab_app/tests/reference/` 为验收数据移植到浏览器，代码在 `web/`。
MATLAB 版进入维护：只修缺陷，不加功能。每个阶段同样有开发 → 测试 → 审计，完成后自动推进。

技术选型：TypeScript + Vite；数值部分纯 TypeScript（Float64Array、CSR 稀疏矩阵），在 Web Worker 里推进；
压力泊松用稀疏 Cholesky 直接解（嵌套剖分排序），扩散系统用修正 IC(0) 预条件共轭梯度（PCG）解到相对残差 1e−12
（规格 §11 允许，只影响舍入）；冻结系数策略按 §3.10（扩散算子每 5 步按当前系数重装、阻力耦合算子按判据）照搬，
才能逐步复现标准答案；界面用 Preact + Canvas 2D。测试用 Vitest 在 Node 下对照标准答案（与 MATLAB 的
`test_reference` 同样的两级判据）。

进度：W0–W5 完成（web-0.1.0、web-0.2.0；W2–W4 合并发布为 web-0.5.0；W5 为 web-0.9.0；最终审计修复后定稿为 web-1.0.0；
紧凑机箱布局为 web-1.1.0）：几何逐项相同，数值例程与 Octave 逐位相同，两个 `fixed_*` 算例第 1/10/13/200 步全部状态
在存储舍入内，13 个分支路径算例与诊断量与 Octave 一致，280² 默认与满载 3000 步稳态均值差 ≤ 0.02°C（v4.2.2 旧布局时
默认差 ≤ 1e−7）；界面功能与 MATLAB 版相同；280² 每步比 Octave 版快约 30%；单文件版可直接双击打开。
能量计账（§8）只用于守恒测试，不移植。后续可做：扩散系统的多重网格预条件（140² 下扩散求解约占一半时间）、
超节点 Cholesky（280² 阻力耦合压力重装约 0.37 s/次）、Firefox/Safari 实测。

- **W0 骨架与几何**：工程骨架；布局数据模型（默认布局、风扇型号、安装位、预设、显卡槽数、JSON 规整与校验）；
  自带数值例程（`grid_interp2`、`edt_nearest`、`pchip_eval`）与稀疏矩阵/PCG；几何构建（§2）。
  验收：`fixed_default`/`fixed_duct` 的 `geometry` 逐项相同，例程与 MATLAB 输出逐位或舍入一致。
- **W1 求解器**：每步顺序（§3）全部环节、热网络与共轭传热、风扇工作点与温控。
  验收：第 1/10/13/200 步快照按两级判据对照（舍入量级）。
- **W2 诊断与稳态**：开口风量、机箱内均温、噪音、评分、智能诊断、`runToSteady`、`steady_long_run`。

## L4：降频与性能、风扇数据与噪音、评分体系（v4.6.0 / web-1.4.0）

用户确认模型目标：比较机箱散热布局与风扇组合在办公、游戏、满载三个场景下对性能与噪音的影响，温度接近真实即可，更看重
气流与热交换的相对差异。据此（MATLAB 与网页同步，规格 §3.6、§4、§5、§6、§9、§10）：
- 降频：CPU/GPU 按频率比计功率（动态 ∝ φ³ + 随结温增长的漏电），加速频率随结温缓降，温度墙闭环把结温压在降频阈，
  最低频率仍压不住才算过热；取代原来"超阈后功率最多降 35%"的开环节流。
- 风扇：型号库改用厂家数据（转速范围、风量、满速噪音、静压）；转速 = max(最低转速, 占空比 × 最高转速)；噪音按风扇定律
  （50·log10 转速比）并加鳍片附加噪音；温控曲线分角色并提供静音/标准/性能三档；显卡风扇低温停转、电源风扇半被动（回差）。
- 评分：按功率分办公/游戏/满载档，性能（频率保持率）、温度（距温度墙）、噪音（响度）、风道（机箱热阻）四项加权。
- 重算全部标准答案与网页对照数据、更新结果表；开发、测试、独立审计同前。

同一实验室 1 m、半消声室）：同一口径下各品牌比厂家标称高 3–9 dB（Noctua 约 +7、Arctic +5–9、Phanteks +3–5），25 dBA 时 NF-A12x25 与

- 风扇型号库：噪音改按同一测量口径（有实测的用实测，没有的按品牌差值估计并注明）；显卡、电源、塔扇风扇按同一口径重估，免得机箱风扇
