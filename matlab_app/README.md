# PC 风道仿真器（MATLAB 版）

紧凑 ATX 机箱侧视 2D 风道与散热仿真（默认机箱深 320 mm × 高 400 mm，只比主板略大，主板贴后壁）：不可压 Navier–Stokes（MAC 交错网格投影法）+
k-ω 湍流 + 共轭传热，配交互式 MATLAB App。版本见 `src/pcflow_version.m`，更新记录见
[`../CHANGELOG.md`](../CHANGELOG.md)，开发计划见 [`../docs/ROADMAP.md`](../docs/ROADMAP.md)，
算法规格见 [`../docs/ALGORITHM.md`](../docs/ALGORITHM.md)，标准答案数据集见 `tests/reference/`。

> ⚠ 2D 定性教学工具：用于理解风道布局、风扇配置与元件温度的趋势，不适用于产品级散热验证。

## 运行环境

- MATLAB R2021a 或更高（`decomposition`、`uifigure` 为核心功能），不需要任何工具箱。
  平流插值（`grid_interp2`）与壁面距离/最近流体格（`edt_nearest`）用项目自带实现，
  MATLAB 与 Octave 走同一套代码，结果只差线性求解的舍入。
- 求解器与数值测试也可在 GNU Octave 8+ 下无界面运行（`setup_paths` 自动加入
  `compat/octave/` 兼容层）；App 仅支持 MATLAB（Octave 下的界面测试用桩对象，
  只验证回调逻辑）。
- 请用 `setup_paths`（`run_simulator`/`run_all_tests` 会自动调用）加路径，不要
  `addpath(genpath(...))`——那会把 Octave 兼容层加进 MATLAB 路径（兼容层在 MATLAB 下会报错提示）。

## 快速开始

```matlab
cd matlab_app
run_simulator          % 启动 App
run_all_tests('quick') % 快速回归（约 1 分钟）
run_all_tests          % 完整回归（含方腔、风道、稳态、守恒 1200 步、湍流，较慢）
run_all_tests('ui')    % 界面测试（MATLAB 驱动真实界面并截图；Octave 用桩对象）
```

## 在 MATLAB 下首次使用前请先跑一遍

开发环境没有 MATLAB，数值部分在 GNU Octave 8.4 下验证，界面只在 Octave 桩对象下验证过回调逻辑。
请在 MATLAB（R2021a+）里按顺序执行：

```matlab
cd matlab_app
run_all_tests('ui')     % 真实界面 + 截图（snapshots/ui_*.png），检查布局、标签页、表格、粒子、导出
run_all_tests('full')   % 数值完整回归（约 20 分钟），含 test_reference：与 Octave 生成的标准答案对照
```

`test_reference` 打印的两行（`fixed_default`、`fixed_duct` 的 max|ΔT|、max|Δu|、max|ΔP|）请原样反馈：
插值、最近流体格、pchip 都是项目自带实现，MATLAB 与 Octave 走同一套代码，差异应只有舍入量级
（≤ 1e−3°C）；若提示"跨平台差异超出存储舍入"或失败，说明还有未统一的内置函数。
如需另存一份 MATLAB 下的对照数据，请写到单独目录，不要覆盖仓库里的数据：

```matlab
make_reference_dataset({'fixed_default', 'fixed_duct'}, fullfile('tests', 'reference', 'matlab'))
```

界面测试里有两项是故意载入错误配置的失败路径测试，命令行会打印"读取配置失败……"与
"重建失败，已保留原布局……"两行（测试模式下不弹对话框），属预期；以最后的 `PASSED` / 错误数为准。
若界面测试报错或截图显示异常，把报错信息反馈即可定位（控件属性名、回调签名等 MATLAB 专有问题
只有真实界面能发现）。

## 界面

- **主视图**：速度、温度、压力（相对机箱外的静压，零压线分开正压区与负压区）、涡量、固体温度、
  温差（当前 − 已保存方案）。配色为感知均匀色图（速度近似 viridis、温度近似 inferno、
  有正负的量用蓝—白—红）。
  - **粒子示踪**：1500 个粒子随流场运动并拖出短尾迹，替代原先每帧重算的流线；暂停或跑到稳态
    后粒子仍在当前流场里继续运动，便于看清稳态风道（空闲约 2 分钟后自动暂停，重新勾选"粒子"继续）。
    粒子在静止空气里停留过久会重生，不会堆积在死区或机箱外。
  - **风量标注**：机箱风扇的净风量附在安装位文字后（如"F2 进 ←24"），电源进/出风口单独标注
    （箭头 = 流向，数字 = CFM，青 = 进、橙 = 出）。
  - 速度、压力视图里固体透明（显示为背景色）；涡量视图红色为屏幕上的逆时针旋转。
  - 机箱四壁外侧的虚线框是风扇安装位，**点击可切换 空 → 进气 → 排气**（绿 = 进气、红 = 排气）。
    机箱内的主板区、CPU 底座（蓝色虚线框）只表示位置，不挡风、不能点击。CPU 双塔散热器画成前后两个蓝框（两组鳍片），
    塔扇（青色）装在两组鳍片中间和前侧。显卡风扇画成橙色虚线框：显卡横插在主板上，侧视看到的是卡的侧边，
    3 个风扇在卡底面朝下、看不到扇叶，求解器在卡底这一层施加向上吹入鳍片的推力。
- **工具栏**（主视图下方）：悬停读数（位置 mm、风速、温度、静压）；下方图切换"温度曲线 /
  风扇工作点"（各机箱风扇与 CPU 塔扇在当前转速下的 P-Q 曲线与实测工作点）；粒子、风量标注开关；
  导出主视图 PNG；录制 GIF（再点一次停止，最多 300 帧）。
- **跑到稳态**：按收敛判据自动停止，运行中再点一次停止；结果显示在温度曲线标题上。
  网格可选"预览 140²"（快；默认机箱下与精确档的结温相差 ≤ 0.8°C、布局排名相同，v4.8.0 及以前的旧配置可能差几度）或"精确 280²"。
- 右侧标签页：
  - **状态**：进气/排气/内部温度、结温、噪音、性能（频率保持率）、评分（按功率分办公/游戏/满载档，见下文"评分体系"）、
    CFD 诊断、智能诊断（温度墙降频、风道效率、主要噪音来源等）。
  - **功率与风扇**：CPU/GPU 功率、电源负载、场景按钮；温控曲线档位（静音 / 标准 / 性能）；全局风扇转速（自动温控 /
    手动百分比）。暂停时改这些设置会自动继续仿真（温度要推进才会变；想看新的稳态再点"跑到稳态"）；
    每台风扇的转速、实测风量、自由风量、工作点静压、噪音（显卡风扇低温停转、电源风扇半被动停转时转速显示"停"）。
  - **风扇布局**：7 个安装位的状态、型号、转速（自动 / 固定百分比）；预设布局；电源仓挡板开孔（载入的配置有开孔时
    可勾选；默认的电源仓挡板只盖住电源、没有开孔，勾选框禁用）；显卡厚度（2.5 / 3 / 3.5 / 4 槽，默认 3 槽约 61 mm，
    散热片与鳍片面积随之变化）；
    CPU 散热器塔扇数量（双塔：1 个装在两组鳍片中间，2 个再加一个在前侧；默认 2 个）；
    标称进/排风量与正负压；安装冲突检查；"应用布局"或"应用并跑到稳态"；
    配置存取 JSON（含布局、功率与风扇设置）。
  - **方案对比**：把当前结果存为方案 A/B/C，逐项对比结温、内温、风量、正负压、噪音、性能、评分（档）、风扇曲线等 20 项；
    "载入布局"回到某个方案；"显示温差"查看当前温度场减去参考方案（需同一网格精度）。

无界面使用求解器：

```matlab
setup_paths();
s = CFDSolverFEM(125, 250, 450);          % CPU/GPU 功率、电源输出负载 [W]，默认布局
info = s.runToSteady();                   % 推进到稳态（约 600–1800 步，DT = 5 ms）
info.final                                % 最近一个窗口的均值，列名见 info.columns
s.thermalNetworks.gpu.T_junction          % GPU 结温（瞬时值）
s.setComponentPower('gpu', 320);          % 改功率
s.reset();                                % 回到初始态

L = layout_apply_preset(layout_default(), 'front_top');   % 换风扇布局预设
s = CFDSolverFEM(125, 250, 450, L, 0.5);                  % 0.5 = 预览网格
R = compare_presets(0.5);                                 % 全部预设跑到稳态并列表对比
R = compare_scenarios({'balanced', 'positive'}, {'gaming', 'heavy'});   % 方案 × 场景批量对比（同网页版对比展示页口径）
plot_compare(R, 'heavy');                                 % 画评分总览、结温与噪音、噪音—温度权衡曲线
```

## 布局配置

`layout_default()` 返回一个只含数据的 struct（可 `jsonencode` 保存）：

| 字段 | 内容 |
|---|---|
| `domain` / `chassis` | 计算域与机箱尺寸（mm；`chassis.sizeMm` 可为标量（见方）或 `[深 高]`，`originMm` 可为标量或 `[x y]`）、机箱 Z 向深度、各壁温度（数值为定温壁，NaN = 绝热，默认绝热）、壁面散热的总传热系数 `panelU.{edge, side}`（W/m²K，四周壁 / 两块侧板，默认 5） |
| `zShare` | 准三维修正：显卡、内存、VRM 占主板到侧板距离的比例（默认 0.8 / 0.2 / 0.2；1 = 固体障碍，< 1 为可以从旁边过风的多孔区） |
| `cpu` / `gpu` / `psu` | 元件矩形（mm，相对机箱原点，x 向前面板、y 向下）、多孔区阻力、热阻与鳍片对流参数（`thermal.h_free/h_forced/h_exp`）、内置风扇、降频阈 `throttleTemp`、频率与功率参数 `dvfs`（可缺省或只给部分字段）；可缺省。显卡厚度用 `layout_set_gpu_slots(L, 槽数)` 修改（散热片高度与鳍片面积一起改），`gpu.slots` 记录槽数；`gpu.ioBlock = true`（v4.9.0 默认）时挡板端（后壁到卡后端、整卡厚）是实心障碍，显卡与后壁之间不过风，缺省为旧模型（这一段可过风）。CPU 的 `fins` 为鳍片外廓，`tower.{stacks, gapMm}` 为塔数与双塔中间间隙（可缺省 = 单塔），`fan.count` 为塔扇数量（1 或 2，可缺省 = 1），用 `layout_set_cpu_fans(L, n)` 修改 |
| `caseFans` | 机箱风扇：安装壁（front/rear/top/bottom）、沿壁中心位置 `alongMm`、进/排气、型号、转速模式（`auto` 跟随全局 / `manual` + `manualPct`） |
| `shroud` | 电源仓挡板上沿与厚度、长度 `lengthMm`（从后壁起；v4.9.0 默认 184 mm，只盖住电源、前方敞开；缺省 = 全宽隔板）、缺口（`gaps` 为空 = 不开孔） |
| `vents` / `solidBlocks` / `porousBlocks` | 被动通风口、实心障碍、多孔障碍（可选） |
| `grille` / `fanDiskMm` | 风扇开口格栅阻力 ζ、执行盘厚度 |
| `fanCurves` | 温控曲线（`fan_curve_profiles('quiet'/'standard'/'performance')`；可缺省 = 标准档）：机箱风扇、塔扇、显卡风扇、电源风扇各一条，显卡另有低温停转、电源另有半被动参数 |
| `acoustics` | 噪音经验参数（工作点、格栅、鳍片附加、各位置修正、底噪、时转时停的修正与判定窗口） |

求解器按 `格 = round(mm / 格距)` 换算，同一配置可用于不同网格细化倍数（常用 0.5 / 1 / 2）。

### 风扇安装位与预设

| 安装位 | F1 前上 | F2 前中 | F3 前下 | T1 顶后 | T2 顶前 | R1 后部 | B1 底部 |
|---|---|---|---|---|---|---|---|
| 壁 / 中心 mm | 前 100 | 前 220 | 前 338 | 顶 100 | 顶 220 | 后 124 | 底 232 |

前/后壁的坐标从顶向下量，顶/底壁从后向前量（相对机箱外沿）。默认机箱深 320 mm、高 400 mm：
ATX 主板（244 mm 深）贴后壁，前部约 72 mm 放前面板风扇。F2 正对 CPU 散热器下部与显卡上半部，
F3 正对显卡风扇下方的进风间隙与电源仓前方的敞开区；T1 在 CPU 散热器正上方。显卡挡板端贴着后壁（实心，不过风），
电源仓挡板从后壁盖到电源前端外 16 mm（184 mm）。电源之后底壁只剩约
150 mm，只放一台 120 mm 底部风扇。`layout_fan_report` 会报出同壁重叠（> 15 mm）、超出壁面
（前/后壁按机箱高、顶/底壁按机箱深判断）、相邻壁角部相碰、与电源重叠、被显卡挡板端挡住（后壁）的风扇。
v4.3.0 之前保存的配置（400 mm 见方机箱）照常读取和计算；但安装位按新的默认机箱定义，旧配置里
顶部 140/260 mm 等不在安装位上的风扇照常运转、安装位表格里不显示。v4.8.0 及以前保存的配置（全宽隔板、前部开孔、
显卡挡板端可过风）按原几何计算，"电源仓挡板开孔"勾选框可用（勾选 = 配置里的缺口）。

预设（`fan_presets`）：2 前进 · 后顶出（默认）、1 前进 · 后顶出、前进后出、前进顶出、底进顶出、
正压（3 进 1 出）、负压（1 进 3 出）、全装。

## 模型概要

| 部分 | 做法 |
|---|---|
| 网格 | 280×280、格距 2 mm（计算域 560 mm 见方）；机箱深 320 mm × 高 400 mm，居中，前后各 120 mm、上下各 80 mm 外部空气；最外 1 格为远场海绵层（阻尼 + 环境温度 + p=0）；机箱 Z 向有效深度 0.15 m |
| 动量 | MAC 交错网格；隐式扩散 → 投影 → 面心半拉格朗日平流 → 浮力、风扇 → 阻力耦合投影 |
| 湍流 | k-ω（Wilcox 2006 + 应力限制器 + 生产限制器）；可选 LVEL 或层流 |
| 温度 | 隐式扩散（定温壁 Dirichlet，其余绝热）→ 半拉格朗日平流（makima）→ 机箱壁散热（两块侧板与四周壁按总传热系数向室内散热）→ 元件热量注入散热体内流体 |
| 准三维修正 | 显卡、内存、VRM 只占主板到侧板距离的一部分（Z 向占比），旁边的空隙可以过风：2D 里按多孔区处理（ζ 按开口比的突缩 + 突扩）。显卡热风从卡的顶边（侧板方向）排出，2D 里穿过 PCB 区向上 |
| 风扇 | 执行盘：厚 12 mm、宽 = 风扇直径，穿盘静压升 = P-Q 曲线工作点 × 风扇定律（超过自由风量时外推为负压） |

### 噪音模型

听者在机箱前侧约 1 m。每台风扇在听音位置的声压级（dB(A)）由下表各项组成，全部风扇再按能量叠加
`L = 10·log10(Σ 10^(Li/10))`（总噪音不低于 0 dB；单扇可低于 0，听不见的风扇不会叠加出声音）；停转的风扇不计入：

| 分项 | 公式 | 说明 |
|---|---|---|
| 转速 | `L_max + 50·log10(n/n_max)`（风扇定律：声功率 ∝ 转速⁵，半速低 15 dB） | L_max 为满速噪音，v4.9.0 起按同一实测口径（1 m，见下文） |
| 工作点 | `6·((0.4 − q)/0.4)²`（q < 0.4），否则 0 | q = 实测流量/当前转速自由风量（低通 0.5 s）；背压过高、接近失速时气流分离加噪，堵死 +6 dB |
| 格栅/滤网 | `10·log10(1 + ζ/2)` | 机箱风扇开口的阻力 ζ：进气（滤网）ζ = 2 → +3.0 dB，排气格栅 ζ = 0.8 → +1.5 dB |
| 鳍片 | 塔扇、显卡风扇 +2 dB | 贴着鳍片吹，来流畸变的附加噪音 |
| 底噪 | 与上面四项之和按能量相加 8 dB(A)（v4.9.0） | 电机、轴承的机械噪音；好的风扇低转速时在 1 m 处低于约 9 dBA，只在转速很低时起作用 |
| 位置 | 前 0、顶 −1、底 −2、后 −3；CPU/GPU 风扇 −3；电源风扇 −4 | 面板方向性与机箱遮挡 |

**时转时停**（v4.9.0）：显卡风扇低温停转、电源风扇半被动，在启停阈值附近会反复启停（默认 3 槽卡约 50 W 起；办公场景显卡进风偏热的布局也会出现）。最近 10 s 内
启停切换 ≥ 2 次即判为时转时停，状态表里风扇名后标 ↻，智能诊断给出提示；间歇的噪音比同样大小的持续噪音更容易被注意到，
评分用的"感知噪音"对这台风扇取其转动时的声级再加 3 dB（BS 4142 的间歇性修正）。显示的"噪音"仍是当前声级。

参数在布局的 `acoustics` 字段（`acoustics_default`），可按自己的机箱和听音位置修改。这些是经验量级
（公开评测里格栅/滤网常见 +1–4 dB、机箱遮挡 2–6 dB），用于比较不同布局的相对差异，不是声学仿真。
"功率与风扇"页列出每台风扇的噪音和能量占比，并给出最响风扇的分项；某台风扇占总噪音能量
超过 40% 时，智能诊断会提示它是主要噪音来源。

风扇型号库（`fan_catalog`）：Noctua NF-A14 / NF-A12x25 / NF-A9、Arctic P14 / P12、Phanteks M25 Gen2 140、
Phanteks T30-120（按 2000 rpm 限速）、机箱原装 120 mm；塔扇按 Thermalright TL-C12C。转速、风量、静压用厂家数据。
**满速噪音 v4.9.0 起改用同一实测口径**（Cybenetics / Hardware Busters 半消声室、麦克风 1 m）：各厂家标称值的测法不同，
同一实验室实测比标称高 3–9 dB 且各品牌差得不一样（Noctua 约 +7、Arctic +5–9、Phanteks +3–5），直接用标称值会让不同品牌的
比较失真。有实测的用实测（NF-A12x25、P12、P14、T30），没有的按同品牌的实测差值估计（NF-A14、NF-A9、M25），显卡风扇按
TechPowerUp 的显卡噪音、电源风扇按 Cybenetics 的电源噪音反推。价格为京东零售价（P14、NF-A9、M25 为估计），"风扇布局"页显示
机箱风扇参考价合计。v4.5 及以前的型号 RX120、RX140（数据并非真实型号）读取配置时自动改为 T30、M25_140。
完整参数与来源见 `docs/ALGORITHM.md` §5。未建模：开口与格栅本身的气流噪音（估算远小于风扇）、同型号风扇的拍频、音调与频谱。

### 评分体系

按 CPU+GPU 名义功率分档（< 187.5 W 办公、< 400 W 游戏、其余满载，三个场景按钮各落一档），四项 0–100 加权：

| 项 | 计算 | 办公 | 游戏 | 满载 |
|---|---|---|---|---|
| 性能 | 频率保持率（CPU、GPU 按名义功率加权）：90% → 0、100% → 100 | 10% | 25% | 35% |
| 温度 | 各芯片距温度墙 (T_limit − Tj)/(T_limit − 环境温度)，取平均；超过 tjmax 记 0；电源超温再 −20 | 15% | 25% | 30% |
| 噪音 | 感知噪音（时转时停 +3 dB）按响度（sone）线性：10 dB(A) → 100、45 dB(A) → 0（19 dB ≈ 92、30 dB ≈ 71） | 60% | 35% | 20% |
| 风道 | 机箱热阻 K = 每 100 W 发热的平均温升（½ 箱内 + ½ CPU/GPU 进风），按对数：K ≤ 1 → 100、2 → 75、4 → 50、8 → 25、≥ 16 → 0 | 15% | 15% | 15% |

办公场景看重安静，满载看重不降频。风道一项只看机箱把热量带走的效率，与散热器好坏无关，便于比较风扇布局。
不同档的总分不能直接比较（方案对比表的"评分（档）"一行写明档位）。办公场景里风扇都在最低转速，总噪音约 12–17 dB(A)
（v4.9.0 起每台风扇有低转速底噪；显卡风扇时转时停的布局感知噪音 18–19 dB），噪音分 91–96，各布局差别主要来自温度与风道两项，
总分差距小，这是实情：办公负载下风扇布局对温度和噪音的影响都不大。

单位：求解器内部速度为网格单位，物理速度 = 网格速度 × VEL_SCALE（(W−2)·格距 ≈ 0.556 m）；
压力视图 P = ρ·VEL_SCALE·格距·p / DT（p 为一步内两次投影的压力之和，远场为 0）；
扩散算子系数为 1/格距²（ν、α 为 m²/s）；浮力、风扇、阻力均换算到同一网格速度口径。

### 方案 × 场景批量对比（v4.7.0）

`compare_scenarios(presets, scenarios, protocol, outFile)` 按网页版"方案对比展示"页的口径（`docs/ALGORITHM.md` §13）计算
风扇布局预设 × 办公 / 游戏 / 满载：每个算例从静止推进 1600 步（自动温控），取后 800 步均值；再把全部风扇固定在全局 40 / 70 / 100%
各接续推进 800 步（"同噪音 / 同温度"的公平比较用）。精确 280² 每个算例约 4000 步，8 × 3 个算例在 Octave 下约 20 小时，
可只算关心的方案与场景，或用 `struct('gridScale', 0.5)` 改预览网格。`plot_compare(R, scenario)` 画评分总览、所选场景的结温与噪音、
噪音—温度权衡曲线。网页版内置了全部 24 个算例的预计算结果（`web/src/compare/data.json`），打开"方案对比展示"页即可查看；
MATLAB 与网页的结果逐项相同（`web/test/fixtures/compare.json` 对照）。

## 已知局限

- 2D 侧视：侧板风扇无法表示；风扇 2D 口径按体积流量守恒（盘宽 × 机箱深度），风速低于真实风扇出口。Z 向流路只用准三维修正
  近似（v4.8.0）：显卡、内存、VRM 旁的空隙与零件本身重合在同一组格里，按开口比折算成多孔阻力；穿过鳍片的气流与从鳍片旁
  绕过的气流在 2D 里分不开，换热只取穿流方向的风速分量。显卡热风从卡的顶边排出后的去向（向上进 CPU 散热器、从卡的两端走）
  由 PCB 区（ζ 26）与散热片横向（ζ 25）两个近似的阻力决定；改 `zShare.gpu` 时应同时改 `gpu.porous.zetaCross`。
  敏感性检查（显卡 Z 向占比 0.7 / 0.85、横向 ζ 15 / 40）：6 个预设的 GPU 排名不变，CPU 排名只有相差 < 0.6°C 的一对互换，
  单个结温变化 ≤ 2°C（v4.8.0 的几何）。显卡挡板端（后面板）的通风孔无法单独表示：v4.9.0 起默认挡板端是实心的（显卡贴着机箱尾部，
  与后壁之间不过风）；没有 `gpu.ioBlock` 的旧配置在散热片后端与后壁之间是 26 mm 的通道，显卡热风可以沿后壁绕回卡下方的进风口。
- CPU 散热器为双塔（v4.5.0 起）：两组鳍片合计的穿流阻力与原来的单块鳍片相同（ζ 8）；热阻与有效面积（v4.8.0 按双塔风冷的
  公开评测标定）不对应具体型号。2D 里空气可以从鳍片上下边横向进出（横流 ζ 60）；中间放塔扇的间隙
  按"风扇框围住"处理，只有横向阻力。v4.4.0 及以前保存的配置（没有 `cpu.tower`）按单塔、1 个前置塔扇计算，结果与当时相同。
- CPU 底座只显示、不挡风（v4.4.0 起）：2D 侧视把底座画在塔式鳍片中间，真实机箱里底座贴主板、鳍片在它外侧。
  v4.3.x 及以前底座是实心块，挡住鳍片中部约一半的过风截面。默认风扇配置下鳍片下方仍有一股向前流的 CPU 热风（约 42°C），
  2D 里很可能被放大（真实机箱里热风可以从 Z 向散走；CPU 散热器没有做部分遮挡修正）。
- F2/F3 两个前面板安装位重叠 2 mm（2D 简化）；重叠的执行盘格同时受两台风扇的体积力，重叠的开口格在开口风量
  统计里计两次（280² 下 F2/F3 共用 1 格，约占开口的 2%）。
- 网格：v4.9.0 的默认几何下预览档（140²）、精确档（280²）与 560² 的 CPU、GPU 结温相差 ≤ 0.6°C（电源 ≤ 0.8°C）、风量 ≤ 1.2%，两档网格的布局排名相同。
  v4.8.0 及以前（全宽电源仓挡板、显卡风扇下方只有窄缝进风）网格影响大得多：560² 的 GPU 比 280² 低 4.4°C，预览档风量差 −18% 至 −4%；
  载入那样的旧配置或自己画出窄缝时，最终比较请用精确档。
- 为了速度，扩散算子每 5 步才按当前系数重装一次（冻结算子）。与每步重装的精确解相比：v4.9.0 的默认、底进顶出标准答案算例（280²）
  结温差 ≤ 0.03°C、风量差 ≤ 0.1%，正压 CPU +0.22、GPU −0.28°C、风量 −1.5%（v4.8.0 时三个算例 ≤ 0.07°C、≤ 0.3%；v4.6.0 时默认布局
  CPU 低 0.6°C、GPU 高 0.4°C、风量低 3%）；旧的 400 mm 布局里
  已对照的 9 个算例中 8 个结温差 ≤ 0.15°C，280² 正压布局 GPU 低约 0.5°C（假平台，详见 `docs/ALGORITHM.md` §3.10、§7）。
  脚本里设 `solver.forceReassemble = true` 可得到精确解（约慢 2–3 倍）。
- 显卡风扇低温停转只看结温。v4.8.0 起被动散热按评测标定（风扇都停时换热风速只计 10%）：默认 3 槽卡约 45 W 以下停转，约 50 W 起
  风扇在停转与最低转速之间来回切换（回差 50 / 55°C；v4.8.0 的 4 槽卡约 55 W 以下停转、60–80 W 时切换），结温在 50–55°C 之间波动，
  长时均值有 ±1°C 左右的起伏。v4.9.0 起这种
  时转时停按间歇性噪音计入评分（感知噪音 +3 dB）；办公场景（35 W）在显卡进风偏热的布局里也会出现。
- 布局之间的温差偏大：默认功率下同样 4 台风扇换位置（前进顶出、正压、负压与默认相比）CPU 差 2–4 K、GPU 差 4–9 K，公开评测里同一机箱改风扇位置一般只差 1–3 K
  （补齐排气或第二进风 3–9 K）。2D 模型缺少 Z 向的掺混，热风与冷风更不容易混合；布局排名可参考，差值宜打折看。
- 对比展示页的口径（8 s、取后 4 s）下办公前进顶出的最高结温在统计窗口里仍在变化（后 1/4 比前 1/4 高 0.5°C，仍在升温，均值偏低），
  页面标"未完全稳态"（v4.8.0 时有 5 个算例）。办公场景风扇都在最低转速、机箱风量只有 10–30 CFM，变化很慢。
- 结温热惯性时间常数取 0.25 s 仅为数值平滑，温度曲线的时间轴不代表真实升温过程；降频（频率比）也按这个时间常数跟随，
  不模拟真实芯片毫秒级的功率限制与 PL1/PL2 时间窗。功率突增（例如从游戏切到满载）时结温会短暂越过降频阈 10 多 °C、
  在约 1 s 仿真时间内可能短暂显示过热，随后回到降频阈；看稳态结果即可。
- 热阻、有效面积与鳍片对流系数按公开评测标定（v4.8.0；没有实机数据，评测数据来自 WebSearch 摘录），不对应具体型号；
  CPU 在评测范围中段，GPU 满载偏热约 2°C。频率与功率模型（φ³、漏电占比、加速频率斜率）是典型量级，不对应具体芯片；
  "性能"只表示频率保持率，不换算成帧率或跑分。
