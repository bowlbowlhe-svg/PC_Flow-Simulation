# PC_Flow-Simulation

PC 机箱风道与散热的 2D 仿真与可视化。

- [`matlab_app/`](matlab_app/)：MATLAB 版（v4.2），说明见 [`matlab_app/README.md`](matlab_app/README.md)
- [`docs/ALGORITHM.md`](docs/ALGORITHM.md)：算法规格（方程、离散、每步顺序、单位、参数），网页版移植依据
- [`matlab_app/tests/reference/`](matlab_app/tests/reference/)：标准答案数据集（固定步数的完整场、稳态结果、基准）
- [`web/`](web/)：网页版（与 MATLAB 版同一算法、同样的界面功能）。**直接用**：下载 [`web/release/pcflow-web.html`](web/release/pcflow-web.html)，双击用浏览器打开；
  操作说明见 [`web/GUIDE.md`](web/GUIDE.md)，开发说明见 [`web/README.md`](web/README.md)
- [`docs/ROADMAP.md`](docs/ROADMAP.md)：MATLAB 定稿 → 网页版的开发计划
- [`CHANGELOG.md`](CHANGELOG.md)：更新日志
